# Образцы вывода: дифф-предложение и финальный отчёт

Справка к скиллу `/refresh-vpn-knowledge`. Открывать на **Шаге 4** (когда собираешь
дифф-предложение оператору) и на **Шаге 7** (когда пишешь итоговый отчёт), если нужен
развёрнутый образец, а не скелет из `SKILL.md`.

Это образцы формы, а не готовый текст: цифры, файлы и формулировки внутри — вымышленные,
подставляй свои реальные находки.

---

## Дифф-предложение (Шаг 4)

Одно предложение = один файл. Показываю «было / предлагаю» дословными цитатами, а не
пересказом: оператор должен видеть, что именно уходит из знания.

```
=== vpn-protocols.md ===

§3.3 «Блокировки Reality в РФ»

БЫЛО (на 2026-05-15):
> Reality с serverName=cloudflare.com работает стабильно. TSPU не блокирует
> TLS-ClientHello с этим SNI.

ПРЕДЛАГАЮ (на 2026-06-15):
> Reality с serverName=cloudflare.com работает в большинстве регионов, но
> с июня 2026 в отдельных регионах наблюдаются эпизодические фейлы
> (источник: ntc.party/t/12345). Рекомендация: для критичных клиентов в этих
> регионах использовать serverName=www.microsoft.com как fallback.

Изменения в sources_checked:
+ https://ntc.party/t/12345-reality-cloudflare-2026-06

Применить? (да / нет / показать ещё контекст)
```

**Почему цитата «БЫЛО» обязательна.** Без неё оператор соглашается вслепую и не замечает,
что новая формулировка тише старой: «работает стабильно» → «работает в большинстве
регионов» — это снятие гарантии, и такое он должен увидеть глазами.

## Финальный отчёт (Шаг 7)

```
✅ Актуализация VPN-knowledge завершена

Файлы обновлены с изменениями: 2
  • vpn-protocols.md — §3.3 (уточнён статус Reality), +1 источник
  • client-apps.md — §2 (новая версия sing-box), +1 источник

Файлы обновлены без изменений (контент актуален, только дата): 2
  • 3x-ui-panel.md
  • 3x-ui-api.md

Tavily-запросов потрачено: 3 / 25 (осталось бюджета)
Web-запросов через WebSearch: 12 (бесплатно)
ADR создан: $INFRA/decisions/00NN-<решение>.md (если был сдвиг)

Все 4 файла теперь last_researched=<дата>.
Следующая проверка сработает по TTL слоя или при первой VPN-задаче.
```

**Две группы файлов в отчёте разделены не для красоты.** «Обновлены с изменениями» и
«обновлены без изменений, только дата» — разного веса: вторая группа означает, что дата
свежести проставлена по `AUTO_REFRESH_DATES=true`, то есть под ответственность оператора,
а не потому, что знание переписано. Смешивать их в один счётчик нельзя — получится
рапорт «обновлено 4 файла», за которым стоит две правки.
