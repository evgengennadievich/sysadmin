# retro/ — память петли самоулучшения агента

Здесь живут результаты скилла [`/retro`](../.claude/skills/retro/SKILL.md) — пострефлексии
сессий. Цель петли: каждая содержательная сессия с агентом-сисадмином доводит его до
идеала, и ни одна находка не теряется между сессиями.

## Что внутри

| Путь | Что | В git? |
|---|---|---|
| `reviews/SESSION-REVIEW-<date>.md` | Полный разбор конкретной сессии | **Нет** (gitignore) — цитирует инфру оператора (IP, домены), PII |
| `reviews/_digest.md` | Рабочий дайджест последнего транскрипта | **Нет** (gitignore) |
| `BACKLOG.md` | Обезличенные находки про агента, ждущие правки в `/dev` | **Да** |

**Почему отчёты не коммитятся:** репозиторий `sysadmin/` публичный (это сам агент).
Сырой разбор сессии содержит инфра-специфику оператора. В трекаемый `BACKLOG.md` находки
переносятся обезличенно — без IP/доменов/имён БД (ADR-0017).

## Цикл

1. Конец содержательной сессии → оператор зовёт `/retro`.
2. Свежий субагент-аудитор судит сессию по транскрипту (5 фронтов, severity MUST/NEVER/MAY).
3. Находки маршрутизируются: баг скилла/персоны → `BACKLOG.md`; архитектура → черновик ADR;
   урок про оператора → предложение в `lessons-learned` (приватный `infra/`).
4. Оператор переходит в `/dev` и закрывает находки по убыванию severity, отмечая их `done`.

## Почему находка обязана объявить основание

Этот бэклог читают будущие сессии — то есть саморазбор **пишет в память агента**. Если в
находку попадёт выдумка, дальше она живёт уже как факт. Так однажды и вышло: `/retro` записал
«агент сломал оператору рабочий VPN», хотя в транскрипте этого не было — формулировка
подтянулась по памяти из другого эпизода.

Поэтому каждая активная находка (`open`) содержит колонку **Основание**: `факт` (подтверждено
транскриптом) или `гипотеза` (не подтверждено — так и остаётся). Правило подпёрто гейтом
[`retro-finding-gate.sh`](../.claude/hooks/retro-finding-gate.sh): строка без основания просто
не запишется. Обоснование — ADR-0021.

Подробности — ADR-0017 и [рубрикатор аудита](../.claude/skills/retro/references/audit-rubric.md).
