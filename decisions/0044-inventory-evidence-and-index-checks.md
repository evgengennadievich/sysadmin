# ADR-0044. Подтверждение правки inventory и проверка индекса Git

Сторож inventory распознаёт команды, которые могли изменить инфраструктуру.
После последней такой команды он ищет успешную правку карточки Markdown в
`inventory/`. В Codex это запись о завершённом применении патча, в Claude Code
это результат правки с тем же идентификатором вызова. Команда чтения, попытка
обновить снимок, обновление дашборда и неудачный патч сами по себе правку
текстовой карты не подтверждают.

Сторож напоминает один раз за ход. Агент сверяет результат с фактическим
состоянием и указывает источник в отчёте. Если карта осталась актуальной,
агент объясняет, чем это подтвердил. Сторож проверяет события инструментов,
поэтому прямые правки из оболочки могут вызвать дополнительную сверку.
Смысл правки и её соответствие серверу проверяет агент.

Проверка перед коммитом сверяет `AGENTS.md` с адаптером и `CLAUDE.md`,
взятыми из активного индекса Git. Из этого же снимка берутся данные для
проверок персоны, знаний, схемы и переносимости. Проверки маршрутов, приватных
данных и секретов читают подготовленные изменения по своим штатным интерфейсам.
Версии на диске можно продолжать редактировать независимо от состава коммита.
