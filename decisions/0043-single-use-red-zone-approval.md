# ADR-0043. Одно подтверждение C.3 на одну попытку

Принято 18.11.2026 по результатам аудита переноса в Codex. Уточняет ADR-0014 и ADR-0022.

Раньше проверка искала слова о риске и копии в десяти репликах. Согласие могло
открыть другую операцию или продолжать действовать после отзыва.

Оператор отправляет две строки по шаблону C.3 в ядре. Первая содержит дословную
команду с объектом, вторая содержит абсолютный рабочий каталог. Подтверждение
читается из последнего сообщения оператора в основной сессии. Вложение, цитата
в пояснении, сообщение субагента и текст из инструмента не дают согласия.

Если отправка Git требует согласия C.3 и согласия на чужие коммиты,
оператор дописывает фразу из ADR-0041 третьей строкой того же сообщения.

Перед разрешением хук эксклюзивно создаёт пустую метку в
`~/.claude/state/red-zone-approvals/` по хешу идентификаторов сессии и сообщения.
Конкурирующие вызовы получают максимум одно разрешение. Повтор после ошибки
требует нового сообщения. Если прочитать журнал или записать метку невозможно,
хук блокирует запрос. В метке нет команды, пути или текста сообщения.

Проверка относится к переданным хуку командам Bash, которые распознал фильтр
красной зоны. Она предполагает целостность журнала и каталога меток. Другие
инструменты и смысл произвольного shell-кода остаются за пределами фильтра.
Доступность хуков в рабочем каталоге проверяется отдельно через Codex.

## Подключение в отдельной папке infra

Из репозитория `sysadmin` запусти `python3 scripts/install-codex-infra-hooks.py "$INFRA_PATH"`.
Скрипт создаёт `.codex/hooks.json` внутри указанной папки, с абсолютным путём к
проверкам в `sysadmin`. Он сохраняет существующий файл, если тот отличается,
и возвращает ошибку. Для сверки добавь `--check`. Этот файл содержит путь на
конкретном компьютере, поэтому его оставляют локальным.

Codex требует одобрения через `/hooks` отдельно для каждого источника. После
одобрения проверь в новом сеансе, что все четыре проверки отмечены как доверенные.
Вызов инструмента должен получить отказ, если он требует C.3, а согласия нет.
При недоступности скрипта защиты перед вызовом инструмента возвращается отказ,
при недоступности проверки inventory после хода появляется предупреждение.
