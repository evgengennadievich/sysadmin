# research/ — исследования, на которых стоят решения по мозгу

Папка для **входного материала**, а не для решений. Здесь лежат конспекты внешних
источников (статьи Anthropic, документация Claude Code, исследования третьих лиц),
на которые потом опираются ADR в `decisions/` и правки персоны.

## Зачем отдельная папка

- **Источник отделён от вывода.** ADR говорит «мы решили так», исследование говорит
  «вот что пишут другие». Смешивать нельзя: чужая статья не наделяется авторитетом
  канона автоматически — сначала своя позиция, потом заимствование.
- **Проверяемость.** У каждого конспекта — URL и дата публикации. Через полгода видно,
  что протухло.
- **Не грузится в контекст.** Материалы читаются по требованию, ядро персоны не трогают.

## Правила ведения

1. Один сюжет = одна подпапка `<тема>-<год>-<месяц>/`.
2. В подпапке обязательны `README.md` (индекс источников с датами и оценкой свежести)
   и `PRINCIPLES.md` (что мы из этого берём).
3. **Дата публикации источника — обязательна.** Нет даты — помечай «дата не определена».
4. Конспект ≠ перевод. Пишем, что применимо к нашему агенту, и что применимо не полностью.
5. Решение, принятое по итогам исследования, оформляется **ADR в `decisions/`** со ссылкой
   сюда. Исследование само по себе ничего не меняет в мозге.
